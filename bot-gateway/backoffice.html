Рассылка в Facebook-группы

Запускает facebook_poster.py на сервере — публикует пост в 33 группах через Playwright.
Требует: установленный Playwright + Chrome-cookies (или переменная FB_COOKIES_JSON).
🍪 Facebook cookies для парсинга групп
Для парсинга FB-групп нужны cookies авторизованного аккаунта.
1. Установи расширение Cookie-Editor в Chrome
2. Зайди на facebook.com как @djprasov
3. Нажми иконку расширения → Export → Export as JSON
4. Вставь скопированный JSON ниже:
